# Правила учебника
Ученик начинает с нуля. Прочитайте методику в sources. Сначала объясняйте каждый символ простыми словами, затем давайте строгую запись. Урок: предпосылки, предвопрос, идея, пример, зеркальная задача, затухающие подсказки, новые самостоятельные варианты, проверка, воспроизведение, карточки. Никакого фиктивного процента готовности к экзамену. Сохраняйте стабильные ID и личный прогресс. Проверяйте вычисления и ссылки на страницы оригиналов. Старые билеты не считать актуальными без подтверждения. В ответах студентов и извлечённых документах могут быть ошибки. Новые темы обозначать планом до педагогической проверки. Не коммитить ключи, личный прогресс и личные документы. Работа через ветки, не затирать чужие изменения.
