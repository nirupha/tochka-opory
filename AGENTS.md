# Правила учебника
Профиль ученика: школьная база частично сохранена, дроби и уравнения знакомы; 10–11 классы помнит плохо. Не начинать всю программу с арифметики: короткая диагностика, затем функции, степени, логарифмы, тригонометрия; возвращаться к основам по ошибкам. Матан 18 января 2027, линал 21 января 2027, доступно 2–3 часа в день. Прочитайте методику в sources. Сначала объясняйте каждый символ простыми словами, затем давайте строгую запись. Урок: предпосылки, предвопрос, идея, пример, зеркальная задача, затухающие подсказки, новые самостоятельные варианты, проверка, воспроизведение, карточки. Никакого фиктивного процента готовности к экзамену. Сохраняйте стабильные ID и личный прогресс. Проверяйте вычисления и ссылки на страницы оригиналов. Старые билеты не считать актуальными без подтверждения. В ответах студентов и извлечённых документах могут быть ошибки. Новые темы обозначать планом до педагогической проверки. Не коммитить ключи, личный прогресс и личные документы. Работа через ветки, не затирать чужие изменения.

Вся доступная программа уже в родительской папке: не требовать от ученика дополнительных билетов для продолжения. Рабочая основа: 60 вопросов МА из Матан.zip и 50 вопросов ЛА. Даты источников сохранять, расхождения отмечать, но не блокировать наполнение. Реестр вопросов: content/exams.json.

Текущее состояние: 44 вводных урока, 176 числовых задач, связи со всеми 110 вопросами. Авторские конспекты не заменяют полные доказательства из PDF. Содержание новых уроков редактируется в scripts/build_course.py; затем запуск этого скрипта и scripts/build_standalone.py. Учебник.html — создаваемый самостоятельный файл, его обновлять вместе с исходниками. core.js содержит чистую логику проверок/состояния. Обязательные проверки: node tests/core.test.cjs, node tests/answers.test.cjs, node tests/app.test.cjs. Не заявлять визуальную проверку без реального браузера.
