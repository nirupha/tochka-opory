# Точка опоры
Учебник для подготовки к матанализу 18 января 2027 и линейной алгебре 21 января 2027. Школьная база частично сохранена; план рассчитан на 2–3 часа ежедневно.

## Открыть
Самый простой способ: открыть **Учебник.html** двойным щелчком. Уроки, вопросы и текст лекций встроены, интернет не нужен. Для ссылок на оригинальные PDF держите папку `sources/` рядом с HTML.

Обычная веб-версия: в этой папке запустите `python3 -m http.server 8080 --bind 127.0.0.1` и откройте http://localhost:8080. На GitHub Pages или другом статическом хостинге публикуется содержимое этой папки без сборщика.

После изменения исходников выполните `python3 scripts/build_standalone.py`, чтобы обновить файл для двойного щелчка. Хранилища прогресса файловой и HTTP-версий могут различаться: переносите прогресс экспортом/импортом. Некоторые браузеры ограничивают localStorage у локальных файлов; в этом случае используйте HTTP-версию.

## Содержание первой наполненной версии
- 44 вводных урока: школьное восстановление, матанализ, линал и геометрия.
- 176 заданий с числовыми ответами и пояснениями; принимаются десятичные числа и простые дроби.
- 60 вопросов МА и 50 вопросов ЛА: каждый связан с соответствующими учебными разделами.
- Конспекты определений, условий теорем, методов и некоторых идей доказательства; полные оригинальные лекции доступны рядом.
- 36 уникальных источников в библиотеке, включая материалы архива Матан.zip. Две старые DOC доступны как оригиналы, автоматическая конвертация в этой среде не удалась.
- Диагностика школьной базы, смешанная практика, карточки повторения, журнал ошибок, сохранение позиции и заметок, экспорт и объединение прогресса.
- Формулы MathML: дроби, степени, корни, индексы и числовые матрицы без внешних библиотек.

## Что означает прогресс
«Пройдено» означает два правильных ответа на проверке базового приёма. Это не доказательство полного владения экзаменационным вопросом. Устная самооценка по вопросам хранится отдельно. Все 110 вопросов связаны с материалом; это **не** заявление о 100% готовности ученика или полном изложении всех доказательств в авторском конспекте.

У задач фиксированный банк: повторная попытка меняет порядок, но не генерирует новые числа. Смешанная практика не заменяет полноценный экзаменационный вариант из `0 вар матан.docx`. Методика реализована частично: пока нет адаптивной генерации задач, полноценной лестницы из трёх подсказок, автоматической оценки доказательств и синхронизации устройств. Длительные доказательства изучаются по исходным лекциям с проверкой по памяти.

## GPT и Claude
Кнопка «Спросить ИИ» готовит контекст темы и задачи для копирования в собственный чат. Она не вызывает модель и не требует ключей. Прямой встроенный чат и автоматическая синхронизация с Claude Artifacts не реализованы.

Каждый клонирует общий репозиторий к себе и запускает свою копию. Код и содержание общие, личный прогресс раздельный. Изменения вносите отдельными ветками через pull request. Правила для помощников: `AGENTS.md` и `CLAUDE.md`.

## Разработка и новые материалы
Основные данные: `content/lessons.json`, `content/exams.json`, `content/sources.json`. ID существующих уроков сохраняйте. Авторская программа воспроизводится командой `python3 scripts/build_course.py`; меняйте этот скрипт для текущих 40 новых уроков, а не только его результат. Первые четыре базовых урока сохраняются из JSON по ID.

`python3 scripts/import_sources.py` импортирует разрешённые учебные PDF/DOCX/DOC из родительской папки. Реестр хранит префиксы SHA256. Старые версии материалов сохраняйте, личные документы не добавляйте. DOCX-извлечение теряет формулы и картинки — сверяйте оригиналы. Архив уже разобран; его учебные файлы находятся в `sources/`.

## Проверки
Без npm и внешних зависимостей:
```
node tests/core.test.cjs
node tests/answers.test.cjs
node tests/app.test.cjs
```
Проверяются 176 числовых ответов, зависимости, ссылки всех 110 вопросов, интервалы, импорт состояния и основные сценарии интерфейса. Тесты интерфейса выполняются с моделью DOM; они не заменяют визуальную проверку реального браузера. В текущей среде тестовый Firefox отсутствует, визуальная проверка не выполнена.

## GitHub
Локальный репозиторий готов. После рабочего входа в GitHub:
```
gh auth login
gh repo create tochka-opory --private --source=. --remote=origin --push
```
Пригласите друга в Settings → Collaborators. Перед публикацией проверьте доступность имени. Никакие ключи и файлы личного прогресса не коммитятся. Репозиторий рекомендуется приватный из-за оригинальных учебных материалов. Приватный GitHub-репозиторий сам по себе не гарантирует приватный или доступный GitHub Pages: возможность хостинга зависит от тарифа и настроек. Для совместной работы достаточно приватного репозитория и локального запуска.
