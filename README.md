# Точка опоры
Локальный учебник матанализа и линейной алгебры с нуля. Стартовый каркас, не завершённый курс.

## Запуск
В этой папке: `python3 -m http.server 8080 --bind 127.0.0.1`
Открыть http://localhost:8080. Сборка, npm и API-ключи не нужны.

## Что работает
4 базовых урока, проверки числовых ответов, зависимости, карточки с интервалами, журнал ошибок, localStorage, экспорт прогресса, поиск по 33 источникам, предварительный план до 18/21 января 2027. Помощь ИИ: копирование контекста в собственный чат. Встроенного модельного чата нет.

## Границы первой версии
Остальные темы обозначены как план, а не готовые уроки. Нет полного покрытия 50 вопросов ЛА, полной реализации методики, автоматического оценивания доказательств, синхронизации устройств, офлайн-кэша и автоматического восстановления прогресса. Контрольные задачи пока фиксированы; повторное прохождение не доказывает перенос навыка. Матан — 18 января 2027, линал — 21 января 2027. Доступно 2–3 часа ежедневно. Школьная база частично сохранена; основной пробел — 10–11 классы. Дроби и уравнения необязательны, старт с функций.

## Вместе с GPT и Claude
Клонируйте один репозиторий каждый к себе. Каждый запускает сервер локально; прогресс раздельный. Код и уроки меняйте через отдельные ветки и pull request. Используйте `AGENTS.md` и `CLAUDE.md`. Кнопка «Спросить ИИ» готовит контекст, но не отправляет его автоматически. HTML-предпросмотр и работа рядом с чатом зависят от приложения. Перенос в Claude Artifact — отдельный адаптер, Git автоматически с артефактом не синхронизируется.

## Обновление материалов
Сохраняйте предыдущую версию, добавляйте новую с датой. `content/sources.json` — реестр SHA256-префиксов и файлов; `content/lessons.json` — уроки со стабильными ID и предпосылками. Скрипт `scripts/import_sources.py` импортирует разрешённые учебные файлы из родительской папки. Проверяйте diff списка перед коммитом. DOC требуют конвертации; извлечение DOCX теряет изображения и формулы. Оригиналы сохранены для сверки. Архив МАТАН.zip ещё не разобран.

После восстановления авторизации `gh auth login`:

Пригласите друга в Settings → Collaborators. Не делайте исходные учебные материалы публичными без проверки прав. Личные заявления исключены.
