существованию равных друг другу односторонних производных. Таким образом, если в точке
не существует или равна бесконечности одна из односторонних производных, а также если
односторонние производные существуют, но не равны друг другу, то общей производной в
этой точке не существует.
       Пример: f ( x ) = x – имеет в точке x = 0 и левую и правую производную, непрерывна
в этой точке, однако, не имеет в ней производной и, следовательно, не дифференцируема в
этой точке.

значений соответствующих многочленов.

функции может быть найдено с любой наперед заданной точностью. Практически можно
сказать, что для нахождения значения любой функции с разумной степенью точности
(предполагается, что точность, превышающая 10 – 20 знаков после десятичной точки,

понятия принципиально различные.

      Очевидно, что в точке перегиба касательная пересекает кривую.
      Теорема 2. Пусть: 1) функция y = f ( x ) непрерывна в некотором интервале,
содержащем точку x0 .
        2) f ′′ ( x0 ) = 0 или f ′′ ( x0 ) не существует
      Тогда, если f ′′ ( x ) меняет знак при переходе через точку x0 , то эта точка является
точкой перегиба.
      Доказательство. Пусть, например, f ′′ ( x ) < 0 при x < x0 и f ′′ ( x ) > 0 при x > x0 . Тогда
при x < x0 кривая выпукла, а при x > x0 кривая вогнута, т.е. точка x = x0 – точка перегиба.
