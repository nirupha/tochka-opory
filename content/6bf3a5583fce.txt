                                     Плоскости в пространстве
      Как уже было отмечено, плоскость относится к первичным понятиям математики. Здесь
мы будем использовать определение, данное в школьном курсе геометрии, а именно плоскостью
в пространстве называется геометрическое место точек, равноудаленных от двух заданных. При
выводе уравнения плоскости будем пользоваться следующими известными фактами, а именно:
      1) Любые три точки, не лежащие на одной прямой однозначно определяют плоскость.
      2) Любые 2 пересекающиеся или параллельные прямые однозначно определяют
         плоскость.
      3) Через любую прямую и не лежащую на ней точку можно провести плоскость и при
         том только одну.

                                       Прямая на плоскости
                                  Уравнение прямой на плоскости

      Прямая на плоскости определяется как геометрическое место точек плосости,
равноудаленных от двух заданных. Прямая на плоскости подобна плоскости в пространстве. Для
получения ее уравнения достаточно в уравнении плоскости убрать одну координату.
      Теорема. Прямая на плоскости в любой декартовой системе координат может быть
задана уравнением первого порядка
                                      Ax + By + C = 0,     (1)
причем постоянные A , B не равны нулю одновременно, т.е. A2 + B2 ≠ 0 .
      Доказательство. Так как любая прямая может быть представлена, как линия пересечения
двух плоскостей, то прямая лежащая в плоскости Oxy можно представить как пересечение
произвольной плоскости π : Ax + By + Dz + C =   0 и плоскости z = 0 . Тогда
                                        Ax + By + Dz + C =
                                                          0
                                       
                                       z = 0
откуда следует уравнение (1).
      Далее, вектор n = ( A, B, C ) – нормаль к плоскости π . Пусть l – прямая, определяемая
уравнением (1). Вектор n ⊥ π , следовательно он перпендикулярен к любой прямой, лежащей в
этой плоскости. В частности n ⊥ l . Вектор n1 = ( A, B,0) является ортогональной проекцией
вектора n на плоскость Oxy . По теореме о трех перпендикулярах n1 ⊥ l . Этот вектор называется
нормалью к прямой на плоскости.
      Уравнение (1) называют общим уравнением прямой на плоскости. Таким образом,
прямая на плоскости является алгебраической кривой 1-го порядка. И обратно, любая
алгебраическая кривая 1-го порядка является прямой на плоскости.
      В зависимости от значений постоянных A , B и C возможны следующие частные случаи:
      - A ≠ 0 , B ≠ 0 , C = 0 – прямая проходит через начало координат
      - A = 0 , B ≠ 0 , C ≠ 0 { By + C =0 } – прямая параллельна оси Ox
      - A ≠ 0 , B = 0 , C ≠ 0 { Ax + C =0 } – прямая параллельна оси Oy
      - A ≠ 0 , B= C= 0 – прямая совпадает с осью Oy
      - A= C= 0 , B ≠ 0 – прямая совпадает с осью Ox
